Six projects

1. Putting design software to work for clients

International client training · software implementation

I trained client teams in Europe, the Middle East and Africa to use design software and apply design data in decision-making. I also implemented software and helped public and private sector clients improve their working practices.

2. From survey data to dredging robot guidance

Ormen Lange, Norway · international software project

I built a 3D seabed surface model from underwater sonar survey data. The model was used to compare the measured seabed with the design, and the data was transferred directly to the dredging robot's guidance system. I automated four data transfer steps into one.

I coordinated the programming team in Bangkok, installed the system at sea and trained the client's users. The system was used to dredge the seabed along a gas pipeline route with centimetre accuracy.

3. Testing AI models and providing expert feedback

Outlier.ai · engineering · quality assurance

I designed engineering-based test cases for training and testing AI models. I evaluated the models' responses and provided structured expert feedback for their development. My work also included internal quality assurance.

4. Access control for paid content

Personal project · Azure · published

I found a service where paid content could be opened without logging in. I developed an Azure implementation that checks access rights on the server. It includes Azure Static Web Apps, sign-in with a Microsoft or GitHub account and acceptance tests for the access checks.

Demo: bit.ly/lumetdemo

5. A model, drawings and quantities in one day

Client assignment, 2026 · Revit · AI-assisted design

I designed an electric forklift charging building for a local hardware store. I connected Autodesk Revit to an AI assistant through the MCP interface and produced the building model, drawings and a bill of quantities with order codes in one day. The material was used for the contractor's tender costing.

6. Moving site quality control from paper to the cloud

Rakennuspalvelu Saneko Oy · client assignment, 2021-2022

I moved site quality control from paper forms to a cloud service. Checklists were used on mobile devices, and the quality control data was compiled into standardised weekly reports.
